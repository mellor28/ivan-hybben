# Ivan Hybben — local profile

A dark static site for AI setup, business automations, and source-backed bots. Slovak is the default language; switch to English with **SK / EN** (`localStorage`). Contact goes through a real mailto to **ivanhybben@gmail.com** — your mail app sends it; the page sends nothing.

## Preview (no server)

- Open `index.html` or `audit.html` from Finder / a browser (`file://` works).
- **Sendable copies:** `index-send.html` (standalone homepage) and `audit-send.html` (standalone audit). Double-click either; no sibling files required. Send both if the homepage audit button should open.
